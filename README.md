# Bio Links

## Project setup
- _Laravel_
- _Tailwind_
- _DaysiUI_
---
## Local environment

### Download project
```shell
git clone git@github.com:EllifasEmanuel/bio-links.git
```
---
### Access project folder
```shell
cd bio-links
```
---
### Create .env file
```shell
cp .env.example .env
```
---
### Run docker containers
```shell
docker compose up -d
```
---
### Run docker containers
```shell
docker compose exec app bash
```
---
### Install project dependencies
```shell
composer install
```
---
### Generate project key
```shell
php artisan key:generate
```
---
### Run project
```shell
npm run dev
```
